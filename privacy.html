Privacy policy

Last updated: 25 November 2026

Torah Shorts Uploader ("Bible uploader") is a private tool used only by the owner of the Torah Shorts YouTube channel to upload that channel's own videos.

What it accesses

With the owner's permission, it uses Google's YouTube Data API to upload videos to the owner's channel and to read basic channel information (the channel name and ID, and the titles of recent uploads, to avoid uploading the same video twice).

What it stores

The sign-in token is stored only on the owner's own computer. A local log records which videos were uploaded and when. No data is sold, shared with third parties, or used for advertising.

Other people's data

The tool does not access, collect or store data about any other YouTube users.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions.

This tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
